# 06 · 制作系统

## 一、功能定位

**给"搜刮来的材料"一个出口，形成成长闭环。**

玩家捡到一堆废金属如果没有用，那就是垃圾；有用途才会思考"要不要冒险去五金店"。

## 二、当前状态

✅ **已完成**

## 三、设计规则（已确定）

| 规则 | 内容 |
|---|---|
| 制作入口 | **工作台**（安全屋卧室），按 E 打开面板，走出范围自动关闭 |
| 为何限定工作台 | 室外不能制作 → 形成"回家整理、出门搜刮"的节奏 |
| 配方数据 | `data/recipes/*.tres`（RecipeData：产物 + 材料消耗），**加配方不改代码** |
| 材料来源 | **废铁五金店**（唯一来源）+ 超市货架少量布料 |
| 材料叠放 | 同 id 可叠 10 个/格 |
| 首批配方 | 木棒 / 铁棒 / 金属矛 / 绷带 /自制护甲(+3护甲) / 铁锹 |

## 四、涉及文件

- `scripts/data/recipe_data.gd`、`scripts/systems/crafting.gd`
- `data/recipes/*.tres`（6 个）
- `scripts/world/workbench.gd`、`scenes/world/Workbench.tscn`
- `scripts/ui/hud.gd`（CraftPanel）

## 五、验收标准

- [ ] 工作台按 E 打开制作面板，走开自动关
- [ ] 材料够显示绿色，缺料显示红色
- [ ] 制作先放产物再扣料，背包满时无副作用
- [ ] 材料与产物都进存档
- [ ] 加新配方只需新建 .tres

## 六、⚠️ 本轮待处理

| 问题 | 说明 |
|---|---|
| 配方是否够用 | 6 条配方对应 7 种材料，部分材料溢出。是否补充配方 |
| 是否与武器分级对齐 | 见 [02-战斗与武器](02-战斗与武器.md)，制作产物算几级 |
| 手雷配方 | DESIGN.md 记录为"缺火药设定，留待以后"，保持不做 |
