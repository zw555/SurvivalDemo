# 10 · 引导系统（内心独白 + 精力疲劳）

## 一、功能定位

**教玩家判断，而不是教按键。**

新玩家不知道该去哪、该带什么。用角色的内心独白表达，
比弹出"按E 拾取"更能让玩家理解处境。

## 二、当前状态

✅ **已完成**（含精力与疲劳子模块）

## 三、设计规则（已确定）

### 3.1 内心独白（ThoughtSystem）

| 规则 | 内容 |
|---|---|
| 触发频率 | 每秒评估一次，同一时刻**至多一句**（优先级裁决） |
| 说完间隔 | 2 秒，防话痨 |
| 展示 | 底部气泡，5 秒后 1 秒淡出 |
| 教程场景（一次性） | 开局饿 / 首次出门 / 首次受伤 / 第2 天起提示警局 |
| 状态想法（可重复） | 饥饿<30(150s) / 口渴<30(150s) / 生命<40(90s) / 装备差出门(300s) |
| 逐步撤掉引导 | 括号里的操作提示只显示到**第 3 天**，之后只留独白 |
| 存档 | 触发记录随存档保留 |

### 3.2 精力与疲劳（StaminaSystem）

| 规则 | 内容 |
|---|---|
| 精力 | 短期资源，上限 100，动态上限 = max(40, 100 − 0.6×疲劳) |
| 奔跑 | Shift，移速 ×1.5，耗 8/秒 |
| 近战 | 耗 8/次 |
| 恢复 | 静止/步行 10/秒，安全屋内 15/秒 |
| 疲劳 | 长期负担，0~100，+20/天 + 奔跑 0.05/s + 近战 0.5/次，**只靠睡眠恢复** |
| 四阶段惩罚 | 轻度25(恢复−10%) / 严重50(−25%、落空10%) / 极度75(−50%、落空25%、攻速−25%) |
| 睡眠 | 床交互，4h/8h 二选一，按**游戏小时**推进时间 |
| 存档 | 精力/疲劳随存档保留 |

**惩罚是"读取时算修正值"，不改写基础属性** —— 这是重要设计约束，改数据结构会连带影响战斗系统。

## 四、涉及文件

- `scripts/systems/thought_system.gd`
- `scripts/systems/stamina_system.gd`
- `scripts/world/day_night.gd`（游戏小时刻度）
- `scripts/player/player.gd`（Shift 奔跑、落空判定）

## 五、验收标准

- [ ] 同一时刻只显示一句独白
- [ ] 第 4 天起不再显示括号操作提示
- [ ] 疲劳四阶段正确切换与解除
- [ ] 睡眠按游戏小时推进，疲劳每小时 −8
- [ ] 极端疲劳下仍可步行撤退（不剥夺控制权）
- [ ] 暂停期间精力疲劳都不累计
- [ ] 存档保留精力/疲劳

## 六、待确认问题

| 问题 | 说明 |
|---|---|
| **疲劳系统是否真的有用** | ⚠️ **未验证**。如果只是让玩家更烦躁而非更有决策，应当移除。需试玩确认 |
| 饥饿与疲劳是否重复施压 | 两套体力系统可能让玩家烦躁 |
| 独白条数是否过多 | 14 条独白，含重复触发 |
