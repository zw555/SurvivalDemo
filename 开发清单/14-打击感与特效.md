# 14 · 打击感与特效

## 一、功能定位

**让"打到了"这件事有实感。**

生存游戏里玩家会死很多次，如果死亡来得莫名其妙（看不清打中没打中、
不知道是谁打的），挫败感会盖过紧张感。

## 二、当前状态

✅ **已完成**

## 三、设计规则（已确定）

命中反馈**五件套**（全部是表现层效果，不引入新系统）：

| 效果 | 实现 |
|---|---|
| 击退 | 玩家与丧尸互相击退，力度/衰减为 `@export` |
| 顿帧 | 命中瞬间全局时间减速（`hit_stop()`） |
| 震屏 | `camera_shake.gd`，trauma 平方衰减 |
| 伤害飘字 | `floating_text.gd`（玩家受击红 / 丧尸受击黄 / 落空提示） |
| 音效 | 5 个程序合成 WAV，带随机音调变化 |

另有：挥砍弧线（朝鼠标方向扇形闪现）、受击闪红、死亡特效。

## 四、涉及文件

- `scripts/fx/death_effect.gd`、`floating_text.gd`、`grenade.gd`
- `scripts/world/camera_shake.gd`
- `scripts/world/main.gd`（`hit_stop()`）
- `assets/audio/*.wav`
- `tools/gen_sfx.py`（音效生成脚本）

## 五、验收标准

- [ ] 命中时五件套全部触发
- [ ] 伤害数字正确对应实际伤害
- [ ] 疲劳导致落空时显示"落空"
- [ ] 丧尸死亡特效继承变体颜色
- [ ] 音效有随机音调变化（不重复感）
