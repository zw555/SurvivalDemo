## 二、每份功能文档的固定结构

所有功能文档都用同一套结构，方便开发对话逐份执行：

```
一、功能定位        —— 这个功能为什么存在
二、当前状态        —— 已实现 / 部分 / 计划中 / 待确认
三、设计规则        —— 已确认的规则（确定的不许改）
四、涉及文件        —— 要改哪些文件
五、验收标准        —— 怎么算做完（开发对话必须逐条验证）
六、待确认问题      —— 还没拍板的，进"待定"不要自己决定
```

## 三、强制工作纪律（给开发对话）

### 3.1 动手前

```bash
cd E:/GameProject/SurvivalDemo
git status --short          # 确认工作区状态
```

⚠️ **本项目可能存在多个对话并行改动**。若发现`data/loot/*.tres`、
`tools/smoke_test.gd`、`scripts/ui/hud.gd` 有**不属于本次任务**的未提交改动，
必须先确认归属再动手，不要直接覆盖。

### 3.2 动手后必跑验证（两条都要过）

```bash
# 1. 冒烟测试（309 项断言）
"E:/Godot_v4.5.2-stable_win64.exe/Godot_v4.5.2-stable_win64_console.exe" \
  --headless --path . -s tools/smoke_test.gd

# 2. 实跑抓运行时错误
"E:/Godot_v4.5.2-stable_win64.exe/Godot_v4.5.2-stable_win64_console.exe" \
  --path . --quit-after 90
```

退出码 0 且无报错才算完成。**测试没过不许提交。**

### 3.3 提交

- 一个功能一次提交，不要把多个功能混在一个提交里
- 提交前再 `git status`，确认没有把别人的未提交改动 `git add` 进去
- 回滚用 `git restore`，不要用 `git reset --hard`

### 3.4 红线

| 情况 | 后果 | 正确做法 |
|---|---|---|
| 手删/改名 `.uid` 文件 | 全项目报错 | 用Godot 编辑器 FileSystem 面板重命名 |
| 改 `.godot/` 里的文件 | 无意义 | 该目录可整个删除重建 |
| 手改 `.import` 文件 | 素材导入异常 | 让 Godot 自己生成 |
| 手改 `project.godot` | 设置错乱 | 只用编辑器 Project Settings 界面 |
| 一次改 20 个文件 | 无法定位问题 | 小步改，每步跑测试 |

## 五、本轮要解决的核心问题

> 详细诊断见 `ROADMAP.md` §2.3

**问题**：熟练玩家 5 分钟、新玩家 8 分钟就能通关。

**根因**（已核算，非猜测）：撤离清单 4 类物资来源高度重叠——食物→超市/军营、
水→超市、汽油→军营、医疗→医院/军营/警局，**全部挤在 3 栋楼**，
最短通关路线纯移动仅 **18 秒**（一天有 600 秒）。

**本轮解法**：
1. **加重并分散撤离清单**（09 任务与结局）→ 强制跑遍5 栋楼
2. **提高守卫密度**（03 丧尸与敌人）→ 每趟搜刮成本上升
3. **消耗 ×3**（01 生存压力）→ 出门前必须规划带多少食物
4. **物资只在建筑内**（04 物资与掉落）→ 探索有明确目的地

改完后预计：**新玩家 20~30 分钟，熟练玩家 12~18 分钟**。

### 本轮同时要做的 UI 改造

玩家反馈三个 UI 问题，已写入 [12-界面与HUD](12-界面与HUD.md)：

1. **装备面板重做** —— 现在是 7 行文字横条，改成**人体轮廓布局**（头顶帽子、
   两侧双手、躯干衣服、下肢裤子鞋子），用形状和位置代替文字传达信息
2. **背包栏收进 Tab 面板** —— 现在锚定屏幕左下角**常驻遮挡画面**，
   合并成「左装备 + 右背包」的 Tab 单页面，战斗时按Tab 关闭屏幕全干净

   （必须同时显示冷却，否则会误导：DPS 上水果刀高于军刀）
