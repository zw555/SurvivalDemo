# 08 · 迷雾与视野

## 一、功能定位

**把"探索"变成真正的探索。**

没有迷雾时地图是一张摊开的图，玩家没有寻找的动力。
迷雾让"我去哪"变成一个问题。

## 二、当前状态

✅ **已完成**

## 三、设计规则（已确定）

| 规则 | 内容 |
|---|---|
| 迷雾网格 | 64px，三态：未探索（全黑）/ 已探索（半透明）/ 当前可见（全亮） |
| 玩家视野 | 近距离 **100px 全向** + 中远**320px / 120° 锥形**（方向跟随鼠标） |
| 视野刷新 | 每0.15s 一 tick，对候选格做射线遮挡判定 |
| 视线遮挡层 | **层值 4**：仅墙/地图边界/建筑墙/门挡玩家视野 |
| 家具 | **不挡玩家视野**（只占层值 2 挡丧尸视线） |
| 窗户 | 仅占实体层，**视线可穿透** |
| 建筑发现 | 路过 420px → 已发现；进过建筑 → 已探索 |
| 地图查看 | `M` 键全屏地图（迷雾底图 + 标记 + 玩家白点） |
| 存档 | 迷雾进度与标记状态随存档保留 |

## 四、涉及文件

- `scripts/systems/fog_of_war.gd`（核心参数都在导出变量里）
- `scripts/ui/map_canvas.gd`、`scripts/ui/fog_label.gd`

## 五、验收标准

- [ ] 未探索区域全黑，隐藏其中的丧尸与物资
- [ ] 家具不再遮挡玩家视野（已修复过沙发挡视野的问题）
- [ ] 隔墙看不见，透窗能看见
- [ ] 迷雾进度与标记随存档保留
