# 05 · 背包与装备

## 一、功能定位

**制造取舍的容器。**

背包容量决定了"这一趟能带回多少"，装备决定了"我能打多狠"。
如果背包无限大，取舍就不存在——这是核心循环的关键约束。

## 二、当前状态

✅ **已完成**（本轮可能需要微调容量相关）

## 三、设计规则（已确定，不要随意改）

| 规则 | 内容 |
|---|---|
| 初始槽位 | **8 格**（`base_slot_count`） |
| 每件物品占格 | 食物/水/武器各 1 格 |
| 材料叠放 | 同 id 材料可叠 10 个/格（`stack_size`） |
| 装备部位 | 7 个：左手/右手/帽子/衣服/裤子/鞋子/背包 |
| 武器规则 | 双手武器占左右手；矛两格且只命中最近一个敌人；匕首只握一只手 |
| 攻击力 | 双手时取伤害更高的一件 |
| 护甲减伤 | **百分比**（总防 ÷20，保底 1 伤） |
| 背包扩容 | 穿上 +`slot_bonus` 格；脱下需放得下 |
| 负重/重量 | **不做**（AGENTS.md §10 明确列为刻意简化） |

## 六、⚠️ 本轮待处理

**清单 13 件 > 初始 8 格**（见 [09-任务与结局](09-任务与结局.md)）

执行方需确认：

| 问题 | 说明 |
|---|---|
| 扩容物够不够 | 目前只有「小背包」+4 格，全图仅几件。玩家要凑 13 格需要 5 个小背包 |
| 是否补充扩容物 | 建议在超市/五金店增加小背包掉落 |
| 是否提高初始槽位 | 若改成 10 格，需同步确认取舍感是否还够|

**这个配平不做完，清单加重会变成"卡死"而不是"取舍"。**
