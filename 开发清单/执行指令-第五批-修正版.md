## 二、根因：迷雾把「看不到」实现成了「涂黑」

### 实际机制（已核实代码）

```
FogOfWar 是 z_index = 90 的 Node2D，在世界之上、HUD 之下
每帧对每个格子 draw_rect(alpha = 0.97 的黑块)
射线被遮挡 → 该格不揭开 → 一直是 alpha 0.97 黑块
```

**关键问题**：射线检测是「从玩家到**格子中心**」，但车辆是 `120×60` 的大块。
**车辆覆盖的每一格，格子中心都落在车辆碰撞体内** → 射线终点在物体内必命中 →
所有覆盖格全黑。

**结果**：你看到的不是「被遮挡的车」，而是「一块黑」。

### 为什么这在美术资源上线后会恶化

| 阶段 | 玩家看到什么 |
|---|---|
|现在（色块车） | 一块黑色矩形 |
| **美术资源上线后** | **半个车被黑块盖住** —— 车轮、车漆、驾驶室细节全丢 |

占位色块时这个缺陷**看起来像设计**，换成美术资源后**就变成明显的 bug**。

**这不是数值问题，是渲染模型问题。** 调视野半径、改碰撞层都改不了它。

---

## 三、正确的遮挡模型

| | 现在（涂黑模型） | 正确（真实遮挡模型） |
|---|---|---|
| 物体本身 | 被黑色矩形盖住，看不见 | **正常渲染，能看清全貌** |
| 物体后面 | 涂黑 | 不渲染/变暗（视线被挡） |
| 美术资源兼容性 | ❌ 会盖掉细节 | ✅ 完整保留 |

**你想要的正是后者**：物体本身清晰可见，只有它**后面**的区域看不到。

## 四、修法：区分「物体所在格」和「物体后面」

### 核心思路（只需改一处判定）

现有代码已有子采样补救机制：

```gdscript
const SUB_SAMPLE_OFFSETS := [(-20,-20), (20,-20), (-20,20), (20,20)]
```

它解决的是「格心恰好在窄家具内 → 永久黑」，
但**对 120×60 的车辆无效**——±20px 的偏移仍然落在车内。

**修法**：射线检测时，**如果射线终点本身就在遮挡物内部**，
则判定为「该格是遮挡物自己所在的格」→ **点亮它**，而不是涂黑。

```
判定逻辑改为：
  1. 射线从玩家到格心，未命中任何遮挡物 → 该格可见（现有逻辑，不变）
  2. 射线命中遮挡物 O：
     a. 如果格心在 O 的碰撞形状内 → 该格是 O 自己 → **点亮**
     b. 如果格心在 O 之外（O 在格心前面）→ 被挡 → 涂黑
```

**效果**：车身覆盖的格子会亮起来（能看清车），
车**后面**那些格子仍然是黑的（视线确实被挡）。

### 具体实现提示

在 `_line_clear()` 或其调用处增加一个判断：

```gdscript
## 射线是否在遮挡物内部结束 —— 用于区分「物体自己所在的格」与「物体后面的格」
func _ray_ends_inside(from: Vector2, to: Vector2) -> bool:
    var space := _player.get_world_2d().direct_space_state
    var query := PhysicsRayQueryParameters2D.create(from, to, SIGHT_MASK, [_player.get_rid()])
    var hit := space.intersect_ray(query)
    if hit.is_empty():
        return false
    # 命中点到目标的距离极小 → 说明目标点就在遮挡物内部
    var hit_pos: Vector2 = hit.get("position", from)
    return hit_pos.distance_to(to) < GRACE_DISTANCE
```

`GRACE_DISTANCE` 建议 **4~8px**（防止浮点误差误判）。

⚠️ 注意：现有的子采样补判**要保留**——两者解决的场景不同：
- 子采样：解决「窄家具恰好卡在格心」
- 本次修法：解决「大遮挡物覆盖整格」

## 五、⚠️ 但这会造成一个副作用（必须处理）

**如果车辆自己所在的格被点亮，那么站在车旁边时，
能"看穿"车看到车后面吗？**

**不会** —— 车后面那些格子的**格心在车外**，射线会命中车，
所以那些格子仍然涂黑。这正是我们要的。

**但要注意**：如果车很小（比如只有 20×20），点亮它自己那一格后，
它后面的格子也会因为子采样（±20px）而点亮。**这就是现有子采样的副作用。**

处理：**本批先不动子采样**，实测后看是否需要按遮挡物尺寸区分。
