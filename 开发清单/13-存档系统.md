# 13 · 存档系统

## 一、功能定位

**让玩家敢冒险。**

没有存档，死亡就是永久失败，玩家会变得极度保守——不敢进危险楼、不敢带好装备。
存档让"尝试"这件事成本可接受。

## 二、当前状态

✅ **已完成**

## 三、设计规则（已确定）

| 规则 | 内容 |
|---|---|
| 快捷键 | **F9 保存 / F10 读取** |
| 暂停菜单 | ESC → 继续 / 存档 / 读档 / 退出游戏 |
| 存档位置 | `user://savegame.json` |
| 存档粒度 | **世界级完整还原**（不只是状态条） |
| 暂停 | 打开暂停菜单时 `get_tree().paused = true` |
| UI 处理 | HUD 设`PROCESS_MODE_ALWAYS` 保证菜单可点击 |

### 存档覆盖范围（已实现）

天数/昼夜/阶段时间· 玩家（生命/饱食/饮水/背包/装备/**位置**）
· 营地仓库 · **全部丧尸（变体/血量/位置）** · **地上物资（物品/位置）** · 箱子内容
· 迷雾进度 · 地点标记 · 任务状态与追踪 · 想法触发记录 · 精力/疲劳

**已知限制**：丧尸的瞬时AI 状态（追击目标/攻击冷却）不存档，读档后从待机重新索敌。

## 四、涉及文件

- `scripts/world/main.gd`（`save_game()` / `load_game()`）
- `scripts/ui/hud.gd`（暂停菜单）

## 五、验收标准

- [ ] F9/F10 有效
- [ ] 读档后玩家位置正确

- [ ] 读档后任务进度、迷雾进度正确恢复
- [ ] 旧存档读取不崩溃
