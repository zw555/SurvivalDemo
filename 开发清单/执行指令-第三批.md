## 二、问题 1：玩家视野小于丧尸视野

### 现状数据（已核实）

```
玩家：全向 100px + 锥形 320px（60°×2）
丧尸：detect_radius 260px，夜晚 ×1.4 → 364px
      另有听觉：挥砍 240px / 枪声 520px / 爆炸 600px
移速：玩家 160 · 丧尸 90（但夜晚 ×1.15，玩家优势不大）
```

**后果**：存在 **160~260px 的「死亡盲区」**——在这个距离内
玩家看不见丧尸，但丧尸能锁定你。玩家发现时已经被追上了。

### 建议数值

**文件**：`scripts/systems/fog_of_war.gd`

```gdscript
@export var omni_radius := 180.0        # 原 100
@export var cone_radius := 460.0        # 原 320
@export var cone_half_angle_deg := 75.0 # 原 60（半角，即 150° 视野）
```

**改后的效果**：
- 全向 180px 已经能覆盖到丧尸的 260px 边缘，贴身不再是盲区
- 锥形 460px 超过丧尸 260px，**玩家看得比它远，才有「绕开它」的空间**
- 视野角 75° 半角（150° 实际）比原来宽，横向逃跑时视野跟随更跟手

⚠️ **代价检查**：视野变大会让迷雾揭开的面积变大，探索更轻松。
如果实测觉得"探索太容易了"，可以只改 `omni_radius`（100→180）
而保持 `cone_radius` 不变，平衡感更可控。

## 三、问题 2：情报解锁导致僵尸持续可见

### 根因（已核实）

```
main.gd:227        _fog.reveal_area(建筑中心, 320.0)
fog_of_war.gd:140  _reveal_around(pos, radius, STATE_EXPLORED)
```

迷雾三态的alpha：

| 状态 | alpha | 僵尸可见 |
|---|---|---|
| `STATE_UNKNOWN`(0) | 0.97 | 看不见 |
| `STATE_EXPLORED`(1) | **0.45** | **看得见** ← 问题在这 |
| `STATE_VISIBLE`(2) | 0.0 | 看得见 |

**情报解锁把整片区域永久标记为「已探索」**，于是玩家读电台/读纸条后，
就获得了该建筑 320px 范围内的免费远程视野——丧尸在里面的一举一动都看得见。

**这让「情报」的价值变成了「免费侦察」，而不是「知道该去哪」。**

### 建议方案 A（推荐）：情报只解锁标记，不揭雾

**文件**：`scripts/world/main.gd`

```gdscript
# 原来
_fog.reveal_area((b.rect as Rect2).get_center(), 320.0)

# 改为：不揭雾，只靠 discover_marker 标记地图
```

`discover_marker(id)` 已经会把地点标记设为「已发现」并显示在M 键地图上，
**这一步已经保留了**。所以只需去掉 `reveal_area` 那一行。

**效果**：情报的价值回归为「地图上出现一个标记，我知道该往哪走」，
但**进门之前你不知道里面有几只丧尸**。

**理由**：这与整个游戏的设计逻辑一致——物资已经"只在建筑内"，
情报如果能提前看到里面有什么，探索的未知感就没了。

### 备选方案 B：加第四态

如果发现玩家读电台后**完全不知道目标在哪**（找不到路），
可以加一个 `STATE_INTELLED` 态：alpha 0.97（和未探索一样黑），
但在地图上画出建筑轮廓。**先试A，不行再上 B。**

### 方案 C（不推荐）：全局调 alpha

把 `STATE_EXPLORED` 的 alpha 从 0.45 改成 0.7——
**会影响所有已探索区域**，玩家走过的地方会变得很暗，代价太大。

## 四、问题 3：Tab 面板太黑

### 现状（已核实）

```gdscript
GearPanelStyle: bg_color = Color(0.07, 0.08, 0.07, 1)   # 接近纯黑
                border_color = Color(0.5, 0.55, 0.45, 0.8)
```

而未探索迷雾的 alpha 0.97 ≈ Color(0.02, 0.03, 0.04)，
**两者几乎一模一样**，所以玩家感觉面板"融进"了背景。

### 建议改法

**文件**：`scenes/ui/HUD.tscn` 的 `GearPanelStyle`

```gdscript
bg_color = Color(0.14, 0.15, 0.14, 0.96)   # 明显提亮（对比现在 0.07）
border_color = Color(0.62, 0.68, 0.55, 0.95)  # 边框更亮更清晰
```

**同时建议给内部元素加对比色**，否则面板变亮了，里面的物品色块
（深棕色木头、灰色石头）可能还是分不清：

| 元素 | 建议 |
|---|---|
| 槽位底板 | 加一层比面板稍亮的底色 + 描边 |
| 物品色块 | 保留原色，但加 1px 深色描边保证边界清晰 |
| 文字 | 确认在浅色面板上仍是浅色可读（可能要改成深色） |

⚠️ **注意**：改亮面板后要检查所有子节点的文字颜色。
Godot 默认字体是深色，深色底看得清；**变亮后可能看不清了**。
