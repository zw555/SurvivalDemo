# 01 · 生存压力

## 一、功能定位

**玩家必须出门的唯一驱动力。**

如果玩家在家里就能活得下去，出门就没有理由——整个生存游戏崩塌。
这个功能负责让"待在家里"永远不是个选项。

## 二、当前状态

🔧 **本轮要改**

当前实现：饥饿、口渴实时消耗，归零后持续掉血；开局满状态。

## 三、本轮确认的设计决定

> 2026-10-15 用户确认：消耗速度 ×3 + 开局带伤 + 低饱食

### 3.1 消耗速度 ×3

```gdscript
# player.gd
@export var food_drain_per_sec := 0.3    # 原 0.1（×3）
@export var water_drain_per_sec := 0.5   # 原 0.167（约 ×3）
```

⚠️ **水必须同步调整**。否则食物 180/天、水 100/天，玩家会**先饿死、
永远渴不着**—— DESIGN.md 里"缺水比缺粮更急，水是每天主要补给压力"
的设计意图就废了。

### 3.2 开局带伤 + 低饱食

| 项目 | 数值 | 说明 |
|---|---|---|
| 初始生命 | **65** | 不是满 100，一醒来就要面对选择 |
| 初始饱食度 | **54** | = 3 分钟量（0.3/s × 180s） |
| 初始饮水量 | **待定** | 建议 50（约 1.6 分钟量，比食物更紧） |
| 安全屋医疗 | 绷带 ×N | 玩家唯一的初始医疗资源 |

**为什么开局带伤**：让玩家一睁眼就面临"先包扎还是先找吃的"。
如果满血开局，第一分钟是纯粹的找路时间，没有决策。

**为什么初始饱食度只有 3 分钟**：玩家必须**立刻**决定去哪，
而不是"先熟悉一下操作再说"。

### 3.3 核算依据

新数值下的时间账：

| 指标 | 数值 |
|---|---|
| 满状态 100 能撑 | 333 秒 ≈ **5.6 分钟** |
| 一天（600 秒）需| 食物 180 · 水 300 当量 |
| 一次完整出门（搜刮+战斗+返回，约 7 分钟） | 消耗 126 食物当量 ≈ 3.6 个罐头 |
| 全图食物（去安全屋后） | 357 当量≈ **2 天** |

**关键设计意图**：满状态 5.6 分钟 ≈ 一次出门的时长。
所以玩家出门前必须算"带几个罐头够这趟"——这就是我们要的取舍。

### 3.4 归零后的惩罚

保持现状：饥饿归零 2 伤/秒，口渴归零 3 伤/秒。

⚠️ **注意**：新消耗速度下，从满状态到饿死只要 **333 秒 ≈ 5.6 分钟**。
如果玩家在外面被缠住，惩罚来得很快。执行方需实跑确认这个强度是否合理，
太严可下调 `starvation_damage_per_sec`。

## 五、验收标准

### 5.1 功能验证

- [ ] 开局生命 **65**，不是 100
- [ ] 开局饱食度 ≈ **54**（约 3 分钟量）
- [ ] 开局饮水量按最终决定值
- [ ] 安全屋有绷带可用
- [ ] **读档不会重复发放初始物品**（关键：否则读档一次白拿一次）
- [ ] 死亡重生后，饱食度/饮水量按规则恢复（**疲劳保留**是已定规则）
- [ ] 3 分钟不进食 → 饱食度归零 → 开始掉血
- [ ] 归零掉血速度符合配置
- [ ] HUD 五条状态栏正确反映新数值

### 5.2 冒烟测试断言（必须新增）

```gdscript
# 1. 初始状态
assert(player.health == 65, "应为带伤开局")
assert(abs(player.food - 54) < 1, "初始饱食度应为 3 分钟量")

# 2. 消耗速率
assert(player.food_drain_per_sec == 0.3)
assert(player.water_drain_per_sec == 0.5)

# 3. 3 分钟不进食 → 归零
运行180 物理帧（headless 下 delta 恒 1/60）
assert(player.food <= 0, "180 秒后应归零")

# 4. 读档不重复发初始物品
save_game(); load_game()
assert(player.health == 保存时的值, "读档不应改变状态")

# 5. 水比食物更早耗尽（设计意图）
assert(water_drain_per_sec > food_drain_per_sec,
    "水应比食物消耗更快")
```

### 5.3 平衡自查（执行方必须实跑）

**必测场景**：
1. **最快通关**：玩家带足食物直接冲超市→医院→警局→军营，需要多少食物、水？
2. **最慢玩家**：只搜超市够不够活到撤离？
3. **开局裸奔**：不放任何食物，玩家能撑多久？

若实测发现明显过难，从这些地方放宽（**优先顺序**）：
1. 超市货架加量（最直接）
2. 其他建筑食物小概率提高
3. 下调消耗到 ×2（最后考虑，会削弱取舍感）
