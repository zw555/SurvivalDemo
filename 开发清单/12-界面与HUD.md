# 12 · 界面与 HUD

## 一、功能定位

**让玩家不用背就能玩。**

生存游戏的信息量很大（生命/饱食/饮水/精力/疲劳、背包、装备、任务、地图）。
UI 的职责是让这些信息**不干扰**核心操作。

## 三、设计规则（已确定）

### 3.1 操作总览

| 按键 | 功能 |
|---|---|
| `WASD` | 移动 |
| `Shift` | 奔跑（×1.5 移速，耗精力） |
| `鼠标左键` | 朝鼠标方向攻击 |
| `E` | 交互（开门/开箱/拾取/制作/睡眠/对话） |
| `Tab` | 装备面板（7 部位） |
| `M` | 全屏地图 |
| `ESC` | 暂停菜单（含任务列表） |
| `F9` / `F10` | 存档 / 读档 |
| 右键 | 丢弃物品到脚下 |

### 3.2 HUD 布局

| 区域 | 内容 |
|---|---|
| 顶部 | 天数 · 白天/夜晚 · 屏幕提示消息条 |
| 左上 | 第 N 天 · 昼夜标签 |
| **五条状态栏** | 生命 / 饱食 / 饮水 / 精力（绿）/ 疲劳（紫，带阶段名） |
| 右上 | 任务追踪（最多 3 卡） |
| 底部中| 内心独白气泡（ThoughtPanel） |
| 底部 | `[E] 提示`（PromptLabel） |
| 面板 | 背包 / 装备 / 容器 / 沙发 / 制作 / NPC / 任务列表 / 睡眠菜单 / 结局（**互斥**） |

### 3.3 硬性设计约束

- **所有面板互斥**：同时只显示一个，避免叠在一起看不清
- **任务追踪面板** `mouse_filter = IGNORE`：**不挡游戏世界点击**
- 物品格显示 `×N`（叠放数量）
- 地面物资显示物品名 + 描边，一眼可辨
- 面板用 anchor 定位，适配不同分辨率
