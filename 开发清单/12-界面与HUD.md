# 12 · 界面与 HUD

## 一、功能定位

**让玩家不用背就能玩。**

生存游戏的信息量很大（生命/饱食/饮水/精力/疲劳、背包、装备、任务、地图）。
UI 的职责是让这些信息**不干扰**核心操作。

## 三、本轮设计决定

> 2026-10-15 用户提出：装备面板太小且无区分度、背包栏遮挡视野、武器分级要体现在游戏里

### 3.1 现状问题（已核实）

| 问题 | 现状数据 |
|---|---|
| 装备面板无区分度 | 7 个 **296×30 的 Button 竖排**，只有「帽子：夹克」这种文字 |
| 装备面板太小 | 单行 30px 高，7 行共 210px，信息密度极低 |
| 背包栏遮挡画面 | `InventoryGrid` **锚定屏幕左下角常驻**，424×108px，不可关闭 |
| 背包会越来越大 | 清单 13 件 + 扩容 → 迟早 20 格以上，排 3 行占用翻 3 倍 |
| 武器分级未体现 | 分级只存在于数据层，玩家完全看不到 |

### 3.2 装备面板：人体轮廓布局

**把 7 个部位槽按人体位置摆放，用形状和位置传达信息，不依赖文字。**

```
                [ 帽子 ]          ← 头顶 · 最小槽
    [左手]                [右手]    ← 左右手分居两侧
                [ 背包 ]          ← 身体后方 · 次大槽
              [  衣服  ]          ← 躯干 · 最大槽
              [ 裤子 ]  [ 鞋子 ]  ← 下肢
```

**槽位尺寸本身就是信息**：

| 部位 | 建议尺寸 | 理由 |
|---|---|---|
| 衣服（躯干） | 最大 | 覆盖面积最大，视觉上"包住"身体 |
| 背包 | 次大 | 体积大 |
| 左手 / 右手 | 中 | 对称，视觉平衡 |
| 裤子 / 鞋子 | 中偏小 | 下肢 |
| 帽子 | 最小 | 头部最小 |

**实现方式（不要美术资源也能做）**：
- 用 `Control` 锚点定位排布，`PanelContainer` + `ColorRect` 拼形状
- 空槽用灰色描边；有物品的槽用 `ItemData.color` 色块填充
- **后续换美术资源时只改槽位贴图，布局代码不动**

**关于"没有文字"**：
- ❌ 完全无文字不可行 —— 玩家不知道是布帽还是头盔
- ✅ **形状 + 颜色 + 位置** 承担主要识别，文字降级为第二行小字或 tooltip
- 这是原型阶段的正确取舍：先用形状建立认知，美术资源到位再增强

### 3.3 背包与装备合并为 Tab 单页面

**现状问题**：`InventoryGrid` 常驻屏幕左下角，战斗时也一直占着画面。

**改法**：

| 改动 | 之前 | 之后 |
|---|---|---|
| 背包栏 | 常驻屏幕左下角 | 收进 Tab 面板 |
| 装备面板 | Tab 单独打开 | 与背包**同屏展示** |
| 布局 | 各自独立 | 左=人体轮廓，右=背包格 |

```
┌─────────────────────────────────────────┐
│ 攻击 25 · 护甲 3 · 移速 +10%← 顶部属性条│
├──────────────────┬──────────────────────┤
│                  │  背包                │
│   人体轮廓        │  [ ][ ][ ][ ][ ][ ][ ] │
│   （装备）       │  [ ][ ][ ][ ][ ][ ][ ] │
│                  │                      │
│                  │  左键=使用/装备       │
│                  │  右键=丢弃           │
└──────────────────┴──────────────────────┘
```

**收益**：
- 战斗时按 Tab 关闭 → **屏幕完全干净**
- 需要时打开 → 一屏看全装备与物品，不用两个面板来回切
- 背包格从 46px 可放大到 56~64px（面板空间变大）

### 3.4 武器分级的三处视觉体现

**光在物品名后缀写「精良」不够**，玩家要能快速判断"这个比我现在的好吗"。

| 体现位置 | 做法 | 作用 |
|---|---|---|
| **① 槽位边框颜色** | 灰=破烂 /绿=普通 / 蓝=精良 / 金=稀有 | 余光一瞥，最快 |
| **② 物品名后缀** | `木棒（破烂）` `军刀（精良）` | 精确对应 |
| **③ 拾取对比提示** | 见下 | **取舍决策的真正落点** |

**③ 拾取对比提示**（最重要）：

```
持有木棒，拾取军刀：
  → 「军刀（精良）比当前木棒强：伤害 17 → 25」，装备按钮高亮

持有军刀，拾取木棒：
  → 「木棒（破烂）比当前军刀弱：伤害 25 → 7」
```

⚠️ **提示必须同时显示攻击冷却，不能只看伤害**：

| 武器 | 伤害 | 冷却 | 实际 DPS |
|---|---|---|---|
| 水果刀 | 8 | 0.35s | 22.9 |
| 军刀 | 25 | 0.45s | 55.6 |

水果刀等级低但 DPS 高于军刀。**只按伤害排序提示会误导玩家。**

### 3.5 部位排序

用户提出"上面头部、中间衣服、左右双手、下面裤子"，实测可行。
建议最终顺序（从上到下）：

```
帽子 → 左手 | 右手 → 背包 → 衣服 → 裤子 | 鞋子
```

⚠️ `Player.EQUIP_SLOTS` 当前顺序是
`[左手, 右手, 帽子, 衣服, 裤子, 鞋子, 背包]`（数据顺序，非显示顺序）。
**不要修改这个数组** —— 存档和其他逻辑可能依赖它。只改 UI 排布。

## 四、既有设计规则（不要改）

### 4.1 操作总览

| 按键 | 功能 |
|---|---|
| `WASD` | 移动 |
| `Shift` | 奔跑（×1.5 移速，耗精力） |
| `鼠标左键` | 朝鼠标方向攻击 |
| `E` | 交互（开门/开箱/拾取/制作/睡眠/对话） |
| `Tab` | **装备 + 背包面板**（本轮合并） |
| `M` | 全屏地图 |
| `ESC` | 暂停菜单（含任务列表） |
| `F9` / `F10` | 存档 / 读档 |
| 右键 | 丢弃物品到脚下 |

### 4.2 HUD 布局

| 区域 | 内容 |
|---|---|
| 顶部 | 天数 · 昼夜 · 屏幕提示消息条 |
| 左上 | 第 N 天 · 昼夜标签 |
| **五条状态栏** | 生命 / 饱食 / 饮水 / 精力（绿）/ 疲劳（紫，带阶段名） |
| 右上 | 任务追踪（最多 3 卡） |
| 底部中 | 内心独白气泡 |
| 底部 | `[E] 提示` |
| **Tab 面板** | 左装备（人体轮廓）+ 右背包（**本轮新增**） |
| 其他面板 | 容器 / 沙发 / 制作 / NPC / 任务列表 / 睡眠菜单 / 结局（**互斥**） |

### 4.3 硬性约束

- **所有面板互斥**：同时只显示一个
- **任务追踪面板** `mouse_filter = IGNORE`：不挡游戏世界点击
- 物品格显示 `×N`（叠放数量）
- 地面物资显示物品名 + 描边
- 面板用 anchor 定位，适配不同分辨率

## 六、验收标准

### 6.1 装备面板

- [ ] 7 个槽位按人体轮廓排布（头顶/两侧/躯干/下肢）
- [ ] **不看文字也能猜出哪个槽是哪个部位**（位置和形状足够清晰）
- [ ] 槽位尺寸有差异（衣服最大、帽子最小）
- [ ] 空槽与有物品的槽视觉可区分
- [ ] 点击已装备的部位能脱下
- [ ] 换美术资源时只需改贴图，不动布局代码

### 6.2 Tab 面板

- [ ] **背包栏不再常驻屏幕**，收进 Tab
- [ ] Tab 内一屏同时看到装备与背包
- [ ] 顶部属性条显示 攻击 / 护甲 / 移速加成
- [ ] 左键 = 使用 / 装备，右键 = 丢弃
- [ ] 容器打开时的存入逻辑仍然正常
- [ ] 背包格从 8 扩到 20 时不溢出面板（可滚动或自动换行）
- [ ] 按 Tab 关闭后**屏幕完全干净**（无任何面板残留）

### 6.3 武器分级

- [ ] 槽位边框颜色按四级区分
- [ ] 物品名带级别后缀
- [ ] **拾取时显示与当前武器的对比（含冷却，不只含伤害）**
- [ ] 拾取更强武器时装备按钮高亮
- [ ] 拾取更弱武器时有明确提示
- [ ] 所有显示位置（背包/装备/容器/地面/任务清单）都带分级
