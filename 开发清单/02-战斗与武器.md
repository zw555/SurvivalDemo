# 02 · 战斗与武器

## 一、功能定位

**给玩家一个"变强"的可见路径。**

战斗不只是打丧尸的手段，更是玩家获得成长感的来源。
武器分级的作用不是平衡，是**让玩家知道自己该去哪**。

## 二、当前状态

🔧 **本轮要改**（新增武器分级，数值不变）

当前实现：16 件武器 + 枪械 + 手雷，三类近战武器（双手/ 矛 / 匕首）。

## 三、本轮确认的设计决定

### 3.2 关键原则：分级不改数值

**这是纯玩家认知层的改动，一个伤害数字都不改。**

理由：现在的武器只有裸伤害值，玩家建立不起认知——
"军刀 25"和"砍刀 17"对他来说没有意义，
他不知道该去市中心还是继续在郊区混。

分级之后，他一看就知道"我现在是破烂级，得去富表碰碰运气"。

### 3.3 实现方式（执行方选择）

| 方式 | 做法 | 优点 |
|---|---|---|
| A·物品名后缀 | `木棒` → `木棒（破烂）` | 零新增字段，一眼可见 |
| B·新增 tier 字段 | `ItemData.tier := 1`，HUD/物品名动态显示 | 数据干净，可排序筛选 |
| C·仅颜色区分 | 物品显示色按级别 | 视觉统一，但玩家要记住色卡 |

**倾向B**（数据驱动，符合项目"数据与逻辑分离"原则），
显示层用 A 的方式（名字带后缀）保证一眼可见。

### 3.4 家里初始武器

用户明确要求：**家里有一把普通武器，不要太强**。

建议给**木棒（1 级破烂）**——玩家打普通丧尸要6~9 下，
能打但打不动，出去搜刮才有换装的动力。

## 五、验收标准

### 5.1 功能验证

- [ ] 每件武器都有 tier 值，且符合分级表
- [ ] **所有武器的 damage 数值一个都没变**（必须逐项比对）
- [ ] 物品名带级别后缀（如 `木棒（破烂）`）
- [ ] 背包格、地面掉落物、容器面板都显示级别
- [ ] 家里初始有木棒
- [ ] 1 级武器在超市/家附近可得，4 级武器在警局/富表可得
- [ ] 装备面板、合成面板的显示都正确

### 5.2 冒烟测试断言（必须新增）

```gdscript
# 1. 每件武器都有合法 tier
for w in all_weapons:
    assert(w.tier in [1,2,3,4], f"{w.display_name} tier 非法")

# 2. 分级与伤害正相关（等级越高伤害越高）
#    注意：允许同级内伤害有差异，但不允许低级伤害 > 高级伤害
for low in tier_1_weapons:
    for high in tier_4_weapons:
        assert(low.damage <= high.damage,
            f"{low} 伤害不应高于 {high}")

# 3. 伤害数值未被改动（回归保护）
assert(weapon_wood_club.damage == 7)
assert(weapon_saber.damage == 25)
assert(weapon_axe.damage == 26)

# 4. 初始持有木棒
assert(player.equipped 中含 tier == 1 的武器)
```
