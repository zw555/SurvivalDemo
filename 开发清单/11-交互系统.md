# 11 · 交互系统

## 一、功能定位

**所有"按 E"的统一入口。**

门、箱子、货架、床、工作台、NPC、拾取物……如果每样东西各写一套按键逻辑，
代码会迅速失控。这个基类是让内容能持续扩充的关键。

## 二、当前状态

✅ **已完成**

## 三、设计规则（已确定）

| 规则 | 内容 |
|---|---|
| 基类 | `Interactable`（Area2D），子类覆盖 `get_prompt()` / `can_interact()` / `interact()` |
| 输入 | `E` 键 |
| 目标选择 | 进入范围自动注册、离开注销，取**最近**的可交互物 |
| 拾取 | **也走 E 键**（不自动拾取）—— 曾因"丢弃后立刻被捡回"改为按 E |
| 容器 | `ContainerBase` 统一开/关/存取/离开自动关 |
| 面板互斥 | 容器/沙发/制作/NPC/结局面板同时只显示一个 |
| 提示 | 屏幕底部显示 `[E] 提示` |

**扩展方式**：加门/箱子/工作台/床/NPC = 新写一个继承 `Interactable` 的场景，**不动框架**。

## 四、涉及文件

- `scripts/interact/interactable.gd`
- `scripts/world/container_base.gd`
- `scenes/world/*.tscn`（每个可交互物）

## 五、验收标准

- [ ] 进入范围显示提示，离开消失
- [ ] 只触发最近的目标
- [ ] 背包满时拾取给出明确提示
- [ ] 容器离开范围自动关闭
- [ ] 面板互斥正常
