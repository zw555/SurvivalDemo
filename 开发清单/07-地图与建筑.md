# 07 · 地图与建筑

## 一、功能定位

**提供探索空间与风险梯度。**

地图是一张大固定图（2400×1600），营地在西南角，城市在东北侧。
玩家从一个角落扩展到整个城市，感受"世界在变大"。

## 二、当前状态

✅ **已完成**（本轮不改结构）

## 三、设计规则（已确定）

| 规则 | 内容 |
|---|---|
| 地图尺寸 | 2400 × 1600，单张固定图，不做场景切换 |
| 可进入建筑 | 5 栋：超市、医院、警局、五金店、军营 |
| 地点标记 | 6 处（含安全屋），三态：未知 → 已发现(420px) → 已探索(进过) |
| 安全屋 | 700×400，五区（客厅/卧室/厨房/厕所/阳台），**南墙一扇门，按 E 开关** |
| 安全屋规则 | **门关着才是安全区**，门开丧尸会追进来 |
| 房间连通 | 60px 门洞 |

### 各建筑定位

| 建筑 | 位置 | 定位 |
|---|---|---|
| 惠民超市 | 市中心 480×360 | **主食物源**（无门，僵尸可进出） |
| 仁爱医院 | 城区北部 440×320 | 医疗来源（南墙敞开） |
| 市公安局 | 城区中部偏西 440×280 | **枪械与弹药唯一来源** |
| 废铁五金店 | 城区东南角 440×280 | **制作材料唯一来源** |
| 城北军营 | 城区北部偏西 480×360 | 终局区域：汽油 + 飞行员老周 + 直升机 |

## 五、验收标准

- [ ] 5 栋建筑都能进入
- [ ] 安全屋门能开关，关门后是安全区
- [ ] 每栋建筑内的容器都能交互
- [ ] 窗户能挡移动但不挡视线
- [ ] 导航网格正确烘焙，丧尸能绕墙走门

## 六、⚠️ 试玩发现的问题（2026-10-15）

**建筑贴邻实测数据**：

| 建筑对 | 边缘间距 | 步行耗时 |
|---|---|---|
| **超市 ↔ 五金店** | **20px** | **0 秒** |
| 医院 ↔ 军营 | 40px | 0 秒 |
| 超市 ↔ 警局 | 40px | 0 秒 |
| 警局 ↔ 军营 | 250px | 2 秒 |

**用户决定：不扩地图，改加街区结构**（成本从2~3 天高风险降到 3~4 小时零风险）。

### 关键发现：地图四周无碰撞墙

`Main.tscn` 里没有 `MapWall` / `MapEdge` 类节点，只有相机 limit在挡
（`main.gd:96-97`）。**玩家理论上能走出地图边缘** —— 造街区时顺带补上边界墙。

### 街区结构的物理层约定（重要）

| 物件 | collision_layer | 效果 |
|---|---|---|
| 街区主墙 | **1** | 挡路不挡视线 → 安全 |
| 车辆车身 | **7** | 挡视线 → 少量躲藏点 |
| 边界墙 | **7** | 挡视线 → 合理 |

⚠️ **绝对不要用 `collision_layer = 3`** —— 该值同时占用层2（丧尸视线），
会让丧尸频繁看不见玩家、追踪行为异常。

**原则：制造「绕路」用层1，制造「躲藏点」用层7。**
若用层7 造长墙，会重新制造第三批刚解决的视野盲区。

⚠️ **最易出问题处**：围墙一加，导航可能把某栋楼烘焙成孤岛。
必须逐栋验证可达性，主街围墙要留≥120px 缺口。

详见 [执行指令-第四批B-街区结构](执行指令-第四批B-街区结构.md)。

## 七、⚠️ 本轮待处理

| 问题 | 说明 |
|---|---|
| 守卫分布 | 每栋楼的丧尸应分布在不同区域，见 [03-丧尸与敌人](03-丧尸与敌人.md) |
| 物资重分布 | 超市成为主食物源后，货架内容需重新配比，见 [04-物资与掉落](04-物资与掉落.md) |
| 地图是否太大 | 核算发现最短通关路线纯移动仅 18 秒，地图偏小（但暂不改结构） |
