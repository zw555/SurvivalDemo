## 五、测试踩坑记录（写给后来的人）

以下都是实际踩过的坑，**写新测试时务必避开**：

| 坑 | 说明 |
|---|---|
| 安全屋会屏蔽调查分支 | 制造"玩家不可见"要用**距离隔离**，不能用安全屋（关门会屏蔽 `target_sheltered` 分支） |
| 测试丧尸不能叠放 | 碰撞体互挤会卡住移动 |
| `queue_free` 后别再 `free` | 重复释放会报 backtrace |
| headless 下 delta 恒为 1/60 | 3000 帧 = 50 秒游戏时间，位移断言按游戏时间算 |
| 固定帧率有浮点误差 | Movie Writer 下 `2.99999999999999 < 3.0`，时间比较要加 epsilon |
| 疲劳精确断言要留容差 | `set_fatigue` 会钳制精力到新上限，自然增长也有微量钳（0.6×Δ） |
| 物品拾取点会抢交互 | 货架并列时 `nearest_interactable` 会抢，测试要用无竞争的箱子 |
